# Правила роботи

- Ніколи не спілкуйся з користувачем російською мовою.
- Усі зміни системи та користувацьких налаштувань внось лише через декларативні конфігурації цього репозиторію. Застосовуй їх штатною перебудовою конфігурації. Не змінюй систему або налаштування напряму командами, ручним редагуванням файлів поза конфігураціями чи тимчасовими обхідними рішеннями.
